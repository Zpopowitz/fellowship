# O*NET occupations

Saved 2026-10-18 for Hackachusetts.

Occupation titles and descriptions from O*NET 30.0. This is not a list of open jobs. The live link is the occupation data file. data.csv is that same table.

Rows in data.csv: 1016

Columns: code, title, description

How to use it

- Spreadsheets: open data.csv in Excel or Google Sheets.
- Fresh copy: run `python fetch.py` or `node fetch.js`. Both call the URL below and save the response.
- The preview on the Hackachusetts site is a few rows of this same table.

Direct request

https://www.onetcenter.org/dl_files/database/db_30_0_text/Occupation%20Data.txt
